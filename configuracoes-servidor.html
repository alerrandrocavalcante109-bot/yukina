Seja bem-vindo às Configurações da Yukina!

Esta página será o espaço para gerenciar as configurações dos servidores do Discord. A ideia é reunir as opções de cada servidor em um só lugar, para que você possa selecionar o servidor desejado e ajustar suas configurações quando os recursos estiverem disponíveis.

Cargos por XP

Defina quais cargos os membros receberão ao alcançar cada nível de experiência no servidor.

Escolha um servidor para ver os cargos por XP salvos.

Hierarquia temporal

Defina quais cargos os membros receberão conforme o tempo de permanência no servidor.

Escolha um servidor para ver a hierarquia temporal.

Multiplicador de XP

Configure multiplicadores para cargos. Quando um membro tiver um dos cargos configurados, o ganho de XP será multiplicado pelo valor definido.

Escolha um servidor para configurar multiplicadores.

Drop & Sorteio

Configure os cargos colecionáveis que concedem entradas extras nos sorteios, os avisos de ganhadores e as exceções de participação.

🎟️ Cargos com entradas extras

Adicione cargos que concedem entradas extras. Use as setas para mudar a ordem; a ordem exibida será mantida.

Escolha um servidor para carregar os cargos.
